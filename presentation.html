07 / The Interface
Designing The GUI

Design Goals

  • Keep every player looking at one shared screen, in‑character
  • Make the terminal feel like a real case file, not a plain console
  • Hide secret information from everyone except the current player

How It Works

  • Color‑coded prompts and ASCII dividers frame each round
  • os / platform clear the screen for "pass the phone" privacy
  • time paces reveals so clues land with dramatic timing
  • Clean menus guide input at every step — no crashes on bad entries

CLOSING ARGUMENT
08 / Why This Case Matters
The Idea Behind The Case

WHODUNIT? started as a simple question: could a classic party game be rebuilt entirely from scratch in Python, with four people each owning a piece of it? Every module — players, clues, votes, scoring — had to talk to the others cleanly, which pushed us to actually practice OOP, state management and teamwork instead of just reading about them.

The result is more than an assignment: it's a working, replayable game that people can genuinely sit down and enjoy — proof that what we learned on this track translates into something real, built together, one file at a time.
